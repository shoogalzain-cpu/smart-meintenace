# Smart Maintenance Operations (`smart_maintenance`) - Odoo 19

Assets, maintenance requests with a controlled workflow, parts and cost roll-up,
preventive plans with scheduled reminders, an Owl dashboard, a QWeb PDF report,
two security groups with record rules, demo data and automated tests.

> Status: written against the Odoo 19 conventions and statically checked (Python compiles, all XML is well-formed,
> every XML id / model / field / button reference cross-checked by script).
> It has NOT been installed or run in a real Odoo 19 instance. See "Potential Errors Before Installation" in GUIDE.md.
